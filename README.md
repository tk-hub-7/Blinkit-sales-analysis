**Developed an end-to-end data analytics project for Blinkit, focusing on sales performance, outlet analysis, customer preferences, and product insights using Power BI, SQL, and Python.
**

Key Highlights:
Built an interactive Power BI dashboard to analyze:
Total Sales
Average Sales
Item Ratings
Outlet Performance
Fat Content Analysis
Item Type Distribution
Outlet Size & Location Insights
Performed data cleaning and preprocessing using Python (Pandas, NumPy)

Used SQL queries for:
KPI calculations
Aggregations
Sales analysis by outlet type/location
Performance comparisons

Created dynamic visualizations including:
KPI Cards
Donut Charts
Bar Charts
Trend Analysis
Matrix Tables
Interactive Filters/Slicers

Implemented business insights such as:
Tier 3 outlets generating highest sales
Medium-sized outlets contributing maximum revenue
Top-performing item categories and outlet types

Tools & Technologies:
Power BI
SQL
Python (Pandas, Matplotlib)
Excel
Business Impact:

This dashboard helps stakeholders monitor sales trends, optimize outlet performance, and identify high-performing product categories for better business decisions.
